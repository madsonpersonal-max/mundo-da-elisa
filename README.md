# Mundo da Elisa — V11

V11 construída a partir da V10 validada em uso.

## Principais correções
- Corrige o texto duplicado “Pingo: Pingo:” nas pistas.
- Mantém a mesma chave localStorage `mundo_da_elisa_v8` para preservar o progresso existente.
- Atualiza a jornada quando novas aventuras são concluídas, sem reduzir uma fase já alcançada.
- Motor adaptativo revisado para reforço, consolidação e desafio.
- Mantém as 30 aventuras, histórico, estrelas, pistas, releituras e Área do Responsável.
- Service Worker V11 com cache próprio e remoção de caches antigos.

## Arquivos
- index.html
- manifest.webmanifest
- service-worker.js

## Regra pedagógica
Erro não reduz estrelas nem encerra a atividade. O sistema oferece releitura, pista e nova tentativa.

## Observação
Os indicadores são educacionais e observacionais; não constituem diagnóstico.
